# Documentation

## Start here
1. [Project instructions](../.github/copilot-instructions.md) define engineering rules and the approval workflow.
2. [Knowledge base](knowledge/README.md) contains reusable architecture and technical lessons.
3. [Approved decisions](decisions.md) records decisions explicitly approved by Oliver.
4. [Requests](../requests/README.md) explains request planning, approval, and implementation.

## Sources of truth
- The approved request defines scope and acceptance criteria.
- Its approved implementation-plan.md defines the intended implementation approach.
- Current code and verified test results describe actual behaviour.
- docs/decisions.md contains explicitly approved durable decisions.
- Request notes contain actual implementation outcomes and remaining work.

Do not treat an unapproved proposal as a confirmed project decision.
